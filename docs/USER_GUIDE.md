# 📖 Smart Task Scheduler - User Guide

Welcome to the Smart Task Scheduler! This guide will help you get started and make the most of all the features.

## 🚀 **Getting Started**

### **First Time Setup**
1. **Create Account**: Click "Sign Up" and fill in your details
2. **Choose Role**: Select Admin, Teacher, or User based on your needs
3. **Login**: Use your credentials to access the dashboard

### **Quick Tour**
- **Dashboard**: Your main hub for overview and quick actions
- **Task Manager**: Create, edit, and organize your tasks
- **Calendar**: Visual timeline of your scheduled tasks
- **Navigation**: Use the top navbar to switch between sections

## 🔐 **Authentication**

### **Login Process**
1. Enter your email and password
2. Click "Sign In" or press Enter
3. You'll be redirected to the Dashboard

### **Sign Up Process**
1. Fill in your name, email, and password
2. Select your role:
   - **Admin**: Full system access
   - **Teacher**: Educational task management
   - **User**: Personal task management
3. Click "Create Account"

### **Password Recovery**
- Contact your system administrator
- Check your email for reset instructions

## 📊 **Dashboard Overview**

### **Statistics Cards**
- **Total Tasks**: All tasks in your system
- **Completed**: Successfully finished tasks
- **Pending**: Tasks waiting to be started
- **Overdue**: Tasks past their due date

### **Quick Actions**
- **Add New Task**: Jump directly to task creation
- **View Calendar**: Switch to calendar view
- **Task Manager**: Access full task management

### **Analytics Charts**
- **Weekly Progress**: Your completion rate over time
- **Priority Distribution**: Breakdown of task priorities
- **Productivity Trend**: Your performance metrics
- **Category Breakdown**: Tasks organized by type

## 📝 **Task Management**

### **Creating a New Task**
1. Click "Add Task" button
2. Fill in the required fields:
   - **Title**: Brief task description
   - **Description**: Detailed explanation
   - **Priority**: High, Medium, or Low
   - **Category**: Work, Personal, Study, or Health
   - **Assignee**: Who's responsible (optional)
   - **Due Date**: When it needs to be completed
3. Click "Add Task" to save

### **Editing Tasks**
1. Find the task you want to edit
2. Click the edit (pencil) icon
3. Modify any fields
4. Click "Update Task" to save changes

### **Deleting Tasks**
1. Find the task you want to remove
2. Click the delete (trash) icon
3. Confirm the deletion

### **Task Status Management**
- **Pending**: Task is created but not started
- **In Progress**: Work has begun on the task
- **Completed**: Task is finished

### **Priority System**
- 🔴 **High Priority**: Urgent tasks that need immediate attention
- 🟡 **Medium Priority**: Important tasks with moderate urgency
- 🟢 **Low Priority**: Tasks that can be done when convenient

## 🔍 **Search & Filtering**

### **Text Search**
- Use the search bar to find tasks by title or description
- Search is case-insensitive
- Results update as you type

### **Filtering Options**
- **Priority Filter**: Show tasks by priority level
- **Status Filter**: Show tasks by completion status
- **Category Filter**: Show tasks by type

### **Sorting**
- **By Priority**: High priority tasks first
- **By Due Date**: Earliest due dates first
- **By Created Date**: Most recently created first

## 📅 **Calendar View**

### **Navigating the Calendar**
- **Month View**: See all tasks for the current month
- **Navigation**: Use arrow buttons to move between months
- **Today**: Click today's date to jump back

### **Task Indicators**
- **Blue Dots**: Tasks scheduled for that day
- **Numbers**: Count of tasks for each day
- **Hover Effects**: See task details on hover

### **Adding Tasks from Calendar**
1. Click on any date
2. Click "Schedule a task" button
3. Fill in task details
4. Task will appear on the selected date

### **Viewing Daily Tasks**
- Click on any date to see tasks for that day
- Tasks are organized by priority
- Quick actions for each task

## 🔔 **Notifications**

## 🚨 **Troubleshooting**

### **Common Issues**

**Can't Login?**
- Check your email and password
- Ensure caps lock is off
- Try refreshing the page

**Tasks Not Saving?**
- Check your internet connection
- Try refreshing the page
- Contact support if problem persists

**Calendar Not Loading?**
- Clear browser cache
- Try a different browser
- Check JavaScript is enabled

### **Performance Tips**
- Close unused browser tabs
- Clear browser cache regularly
- Use a modern browser (Chrome, Firefox, Safari, Edge)

## 🔒 **Security Best Practices**

### **Account Security**
- Use a strong, unique password

- Enable two-factor authentication if available

### **Data Privacy**
- Don't store sensitive information in task descriptions

- Review your task history regularly
